# ORYX Print Network — Foundation Blueprint v0.1

ORYX is a digital commercial and operating institution for design, printing, advertising and customized manufacturing. It owns the customer journey while production can be routed through an approved network of specialized partners.

**Customer flow:** Discover → Configure → Quote/Price → Design → Approve → Route → Produce → QC → Deliver → Pay → Reorder.

## Public pillars
1. Deep services catalog with independent service pages.
2. Sellable packages built around industries and customer goals.
3. ORYX Projects Lab for publications, campaigns and initiatives invented by ORYX.
4. Production Partner Network for printers and specialized manufacturers.
5. Digital magazine as an SEO and knowledge engine.

## Operating modules
Catalog & Service Builder, Pricing, Smart Orders, Quotes, Design Studio, Production Routing, Partner Network, Procurement, Work Orders, QC, Logistics, CRM, Packages, Projects Lab, Finance, Partner Settlements, CMS/SEO, Customer Portal, Partner Portal, RBAC, Audit, Analytics and AI Assistant.

## Core architectural rule
A service is data, not a hard-coded form:

Department → Category → Service → Variants → Dynamic Fields → Materials → Pricing → Design Requirements → Workflow → Partner Capability → QC → Packaging → Delivery.

This permits 377, 500 or 1,000+ services without rebuilding the application for every product.
